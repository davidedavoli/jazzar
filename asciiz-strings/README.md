The programs in this directory illustrate the handling of zero-terminated ASCII
strings.

  - `hamming-distance.jazz` compares strings of equal lengths and tells how many of their bytes differ
  - `isogram.jazz` computes whether there are no repeated letters (case-insensitively)
  - `rot13.jazz` implements the [ROT13](https://en.wikipedia.org/wiki/ROT13) substitution
